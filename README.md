# Лабы по профильным предметам

В этом репозитории собраны лабораторные работы только по профильным предметам за 1 и 2 курсы программы **11.03.02 "Программирование в инфокоммуникационных системах"** университета ИТМО. 
Вышмат, физика, английский и т.д. не включены.

### 1 курс
- Алгоритмы и структуры данных -- работа с алгоритмами на языке python
- Инфокоммуникационные системы -- LaTeX и проектирование UML, DFD, IDEF0, IDEF3, составление ТЗ по ГОСТ
- Компьютерные сети -- работа в Cisco Packet Tracer с сетями
- Программирование -- программирование на python, работа с ООП, Tkinter
- Введение в ОС Linux -- работа с Debian, терминалом, файловой системой, Bash
### 2 курс
- Администрирование платформ на ОС Linux -- Развёртывание web-приложений
- Методы моделирования информационных процессов и систем -- проектирование UML, DFD, IDEF0, IDEF3
- Объектно-ориентированное программирование -- ООП на C#
- Проектирование и реализация баз данных -- работа с SQL-запросами, PostgreSQL
- Проектирование инфокоммуникационных систем -- проектирование
- Промышленная маршрутизация и управление трафиком -- работа с сетями в ContainerLab с Mikrotik RouterOS
